# 赶海日记 · Beachcomb Diary — Vertical Slice v0.3

试玩地址：<https://fabulous-wendy.github.io/beachcomb-diary/>

本版是方案 C「奶油色海边水彩＋纸质贴纸」的**前三关 UI/玩法样板**，不是完整商业版。素材来自先前确认的《赶海日记》独立透明 PNG 素材库；网页运行采用独立 WebP 图片，保留分层组合，不再用程序绘制的人物占位符代替角色。

## 实现范围

- 主页：水彩海岸场景、真实 PNG 派生的 logo、主角与宠物、主按钮。
- 地图：潮汐群岛、前三片海岸依次解锁、预留后续章节。
- 第一关「暖风沙湾」：空壳观察、沙洞与蟹类线索、动态摆放、随机垃圾。
- 第二关「石缝潮池」：海藻与礁石生境、缓慢爬行或摆动的生物、随机隐蔽点。
- 第三关「月牙泥滩」：弹涂鱼、招潮蟹、泥滩线索、海草与藻类。
- 16 种生物／海草／海藻的分类型图鉴和收藏小屋；每关完成后的分享入口。
- 海岸环保支线：随机垃圾、分类、安全报告尖锐危险物、5 件清理后工坊解锁、虚拟手工、环保小达人。
- 浏览器本地保存：关卡、图鉴、环保积分与工坊，存档键 `beachcomb-diary-v3`。

## 架构

```
index.html             入口
styles.css             视觉主题 / UI 组件 / 行为动画
game.js                数据驱动的地图、关卡、物种、收集与环保逻辑
assets.json            资源目录，独立文件名 -> 相对路径
assets/bg/             3 张场景背景
assets/ui/             品牌、开始按钮、图鉴标签等
assets/chars/          主角与角色姿态
assets/shells/         贝壳、寄居蟹、海星等
assets/animals/        螃蟹、鱼、海参等
assets/plants/         海草与藻类
assets/trash/          海洋垃圾及环保徽章
assets/collect/        收藏罐、图鉴等
assets/props/          潮间带线索和工具
```

功能数据与美术资源分离。未来扩展关卡时，应在数据层定义生境、物种池、行为和任务，沿用同一套 UI 组件和资源规范。原 PNG 素材库另行保存，WebP 仅是网页端优化文件。

## 当前限制

- 真实完整美术分层尚不等于 PSD/Spine 骨骼文件；透明素材是独立图片，动画是 CSS 层上的位移、摆动与缩放。
- 场景原画本身可能已有小型贝壳或海洋生物绘入背景，它们不是可点击的互动对象。下一轮可按天空、海水、前景石块、藻类分成更细的可动图层。
- 目前每片海岸是一个可重复进入的样板关卡，**不是 12 关成品**；地图后续区域属于规划位。
- 与旧 v0.2 存档不自动互通，以免污染已存数据。真正上线前需要确定迁移方案。
- 网页分享到系统分享或复制文字，尚未接入微信小游戏原生接口。
- 图片已通过文件完整性和本地逻辑检查；此执行环境阻止 Chromium 打开本地 HTTP/文件，**无法宣称已在 iPhone Safari 实机通过视觉 QA**。

## 测试方法

1. 用静态文件服务器运行本目录，例如 `python3 -m http.server 8000`，在浏览器打开 `http://localhost:8000`。
2. 从首页进入海岛，体验第一关，完成 3 次有效观察后过关。每关可使用“换一次潮汐”更换布局。
3. 重复完成第二、三关，确认地图解锁、图鉴、收藏室及本地刷新持久化。
4. 点击垃圾，尝试正确/错误分类；危险鱼钩应选择“请成年人处理”。
5. 完成 5 次安全垃圾分类，可体验环保工坊；完成 8 次可获得环保徽章。

## 验收优先级

首先检查画风、角色比例、图层画面、按钮和字体，再检查玩法节奏、随机生境、图鉴与环保反馈。只有这套 Vertical Slice 通过验收，才继续追加第 4–12 关。
