# 赶海日记 · Beachcomb Diary

一个面向儿童与成年人的**奶油治愈贴纸风** HTML5 赶海探索游戏；在 GitHub Pages 上免费运行，无需 AppDeploy、服务器、登录或付费 credits。

**试玩地址：** https://fabulous-wendy.github.io/beachcomb-diary/

## 当前版本：v0.2.0 · 第一轮可玩升级

- **潮汐群岛地图**：六片风景，前 3 区可通过通关逐一开放，后 3 区为未来章节。
- **三个主题关卡**：暖风沙湾、石缝潮池、月牙泥滩，每关有独特地形、生物池与线索。
- **动态观察**：螃蟹横向奔跑、鱼和虾短距离游动、寄居蟹探头、海藻摇摆、海星缓行。
- **每次探索位置变化**：可观察物种、沙洞、礁石、海藻与海洋垃圾重新安排。局内点击线索揭示生物，再点击记录观察。
- **真实海洋生态灵感**：共 16 类记录，包含甲壳类、贝类、棘皮动物、鱼类、海洋植物和藻类；分区图鉴附简短知识。
- **分类收藏屋**：海洋发现、贝壳标本、海藻植物、环保手作、守护成就。
- **环保探索**：随机海洋垃圾、正确分类、危险废弃鱼钩报告成年人、环保点数、解锁环保工坊与手作。
- **通关结算与分享**：完成 3 次发现后通关，可使用设备分享接口或复制链接。
- **浏览器本地保存**：图鉴、通关进度、工坊、环保积分写入 localStorage。

## 本轮边界（并未实现）
- 并未完成之前概念图等级的全部美术资产或完整角色逐帧动画；当前为统一风格的内嵌 SVG 可玩切片。
- 后 3 个地图仅有预览占位，不是可玩的关卡。
- 暂未接入服务器账号、跨设备存档、多人、每日潮汐实时数据或微信原生分享 API。
- 此版本是 **GitHub Pages 网页 Demo**，不是经微信小游戏审核发布的正式小游戏。
- v0.2 使用独立本地存档，以免无意改动旧版存档；旧版存档未进行自动迁移。
