# 赶海日记 · 海岸守护计划体验版

无需服务器和 AppDeploy，可直接通过 GitHub Pages 托管的 HTML5 赶海小游戏。

## 当前真正实现的功能

- 奶油色贴纸风，三个原有赶海探索关卡（暖风沙滩、礁石浅滩、水光潮池）。
- 贝壳、海星、寄居蟹等图鉴记录、基础收藏小屋与浏览器 localStorage 进度保存。
- 每次进入关卡随机出现 3 件可安全分类的模拟海洋垃圾，部分重玩另有危险鱼钩。
- 垃圾分类交互：可回收、其他垃圾、危险物品交由成年人处理。
- 累计安全清理 5 件解锁海岸工坊，8 件获得「环保小达人」徽章。
- 使用游戏内回收积分解锁 3 种虚拟工艺品，自动进入收藏小屋的环保作品区。
- 关卡结算时尝试系统分享（可用时）或复制网址。正式微信小游戏分享尚未接入。

## 如何本地运行

在浏览器打开 `index.html`，或者在项目目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/`。单文件，不依赖第三方 CDN。

## GitHub Pages 免费部署（需要 GitHub 账号）

1. 在 GitHub 使用现有 **Public** 仓库，仓库名 `beachcomb-diary`，分支 `main`。
2. 将 `index.html`、`.nojekyll` 和 `README.md` 上传至仓库根目录。
3. Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，文件夹 `/(root)`，点击 Save。
5. 发布成功后项目站点通常为 `https://<你的用户名>.github.io/beachcomb-diary/`（以 GitHub Pages 实际状态为准）。

## 游戏设计约束

现在只有 3 关，12 关地图、真实物种习性动画、动态岛屿大地图和完整海洋分类图鉴属于后续计划，**尚未实现**；不要把这版当成完整微信小游戏。所有清理与工艺制作仅限虚拟示意，不鼓励儿童现实中触碰鱼钩、针具、玻璃、危险废弃物或受污染材料。真实清理应由成年人陪同并遵守当地规定。

项目用于非商业游戏原型验证；本地进度保存在浏览器中，清除浏览数据可能重置。任何互联网分享请留意保护儿童个人信息。
